# RPG Roguelike

> Курсовой проект по дисциплине «Программирование на языках высокого уровня»  
> НГТУ им. Р.Е. Алексеева · Кафедра КТПП · Группа 25-ИСТ-2

Двухмерная action-RPG в жанре roguelike на **C++17** с использованием библиотеки **SFML 2.6**.

---

## Возможности

### Геймплей
- Игровой цикл с **delta time**, окно 1280×720, 60 FPS
- Движение в 8 направлениях (WASD / стрелки), стрельба в курсор (ЛКМ)
- **Рывок (dash)** — Space/Shift, кратковременный иммунитет к урону, откат 1 с
- **3 этажа** с нарастающей сложностью

### Враги
| Тип | Поведение |
|-----|-----------|
| **Slime** | Преследует игрока, урон контактом |
| **Shooter** | Держит дистанцию, периодически стреляет |
| **Berserker** | Медленно сближается, затем выполняет быстрый рывок |
| **Boss** | Фаза 1 — 3 снаряда, фаза 2 (HP < 50%) — 5 снарядов |

### Уровни
- **Процедурная генерация** этажей: 6–10 случайно соединённых комнат
- Типы комнат: `START` `NORMAL` `ITEM` `SHOP` `BOSS`
- Двери заблокированы до уничтожения всех врагов
- **BFS-навигация** врагов с обходом препятствий
- Текстурный рендеринг тайлов (стены, углы, пол)

### Прокачка
- **Система опыта**: уровни 1–20, опыт за убийства
- При каждом повышении уровня — **выбор одного из трёх апгрейдов**

| Апгрейд | Эффект |
|---------|--------|
| Health Boost | +20% максимального HP |
| Damage Boost | +15% урона |
| Speed Boost | +10% скорости |
| Fire Rate | +20% скорострельности |
| Regeneration | 0.5 HP/с при неполном здоровье |
| Piercing Shots | Снаряды пробивают врагов насквозь |
| Explosive Shots | Взрыв при попадании |
| Lifesteal | 10% урона → HP |
| Double Shot | 3 снаряда вместо одного |
| Shield Charge | Убийство врага восстанавливает щит |
| Dash Reset | Убийство врага сбрасывает откат рывка |
| Greed | +50% монет |
| Critical Hit | 15% шанс удвоить урон |

### Предметы и магазин
- Аптечка (+30 HP), +Урон, +Скорость, Щит, Монеты
- Магазин (`E` — покупка за монеты)

### Интерфейс
- **HUD**: полоска HP, счёт, этаж, монеты, иконки предметов, полоска опыта
- **Миникарта** этажа с цветовым кодированием комнат
- Экраны: Главное меню · Пауза · Game Over · Победа

### Настройки
- **Управление**: перебиндинг 8 действий, сохраняется в `controls.txt`
- **Графика**: полноэкранный режим, VSync, лимит FPS (30–240)
- **Звук**: ползунки Master / Music / SFX

## Управление (по умолчанию)

| Клавиша | Действие |
|---------|----------|
| `WASD` / стрелки | Движение |
| ЛКМ | Выстрел в направлении курсора |
| `Space` / `Shift` | Рывок |
| `E` | Взаимодействие / покупка |
| `Esc` | Пауза / меню |
| `1` `2` `3` | Выбор апгрейда при повышении уровня |

> Все клавиши можно переназначить: **Settings → Controls**

## Сборка

### Требования
- **CMake** 3.16+
- Компилятор C++17: **MSVC 2019/2022**, GCC 9+, Clang 10+
- Доступ в интернет при первой сборке (FetchContent загружает SFML 2.6.1)

> SFML линкуется **статически** — рядом с `.exe` не нужны никакие `.dll`

### Windows (командная строка)

```bat
cmake -S . -B build
cmake --build build --config Release
build\Release\RPG_Roguelike.exe
```

### Windows (Visual Studio)

1. Открыть папку через **File → Open → Folder**
2. VS автоматически обнаружит `CMakeLists.txt`
3. Выбрать конфигурацию `x64-Release` → запустить `RPG_Roguelike`

### Linux / macOS

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build
./build/RPG_Roguelike
```

## Шрифт

Поместите файл `font.ttf` в папку `assets/`. Рекомендуются шрифты с поддержкой кириллицы:
- [DejaVu Sans](https://dejavu-fonts.github.io/)
- [Noto Sans](https://fonts.google.com/noto/specimen/Noto+Sans)

Если шрифт не найден — игра запустится, но текст не будет отображаться.  
`AssetManager` также ищет шрифт в системных путях Windows/Linux/macOS.
